Tokens y guía de estilo

Paleta neutra con un solo acento, tipografía Inter, grilla de 4px. "El color informa, no decora": se reserva para estados (vencida/prioridad/completada) y para lo que el usuario elige (carpetas, tareas, tags).

Principios

Mobile-first, a una mano
Acciones primarias al alcance del pulgar.
Pocos elementos
Lo opcional aparece solo cuando se pide.
El color informa
Nunca decora: base neutra + 1 acento.
Rápido
Crear tarea en segundos, sin spinners locales.
Feedback inmediato
Consistencia visual en cada acción.
